# User Story Template

## Title
[Short description of the feature]

**As a** [type of user],

**I want** [a feature or action],

**So that** [the benefit or business value].

## Acceptance Criteria

**Given** [an initial condition],

**When** [an action occurs],

**Then** [the expected result].

## Additional Details

- **Priority:** High / Medium / Low
- **Story Points:** 1 / 2 / 3 / 5 / 8
- **Sprint:** Sprint 1 / Sprint 2 / Sprint 3
- **Label:** Enhancement / Technical Debt
- **Status:** New Issues / Ice Box / Product Backlog / Sprint Backlog / Done

## Example: Create a Customer Account

**As a** customer service representative,

**I want** to create a new customer account using a REST API,

**So that** customer information can be stored and managed.

### Acceptance Criteria

- Given valid customer information, when a POST request is sent to the accounts endpoint, then a new account is created.
- The API returns HTTP status code 201 for successful creation.
- Invalid input returns an appropriate error response.
